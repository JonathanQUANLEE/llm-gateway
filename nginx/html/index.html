模型与价格

倍率为计价刻度：1× = $2 / 百万输入 token；扣费 = tokens × 模型倍率 × 分组倍率，输出 token 另乘补全倍率。模型与倍率以控制台价格页为准，持续上架中。

模型倍率说明
gpt-4o-mini0.075×轻量通用 · 输出另乘 4×（补全倍率）
gemini-flash0.20×高速推理档
deepseek-chat0.14×高性价比 · 补全倍率 4×
gpt-4o1.25×旗舰通用 · 输出另乘 4×
claude-sonnet1.5×代码与长文本强项

> 换算：倍率 × $2 = 每 100 万输入 token 的美元价。

快速开始（三种方式）

① 网页客户端零门槛

  1. 打开聊天页：http://localhost:8080
  2. 输入访问码（见管理员）
  3. 设置中填接口地址 http://localhost:3000 + 你的令牌
  4. 选择已上架的模型即可开始

② 开发工具接入Cursor / Agent

任何支持自定义 OpenAI 接口的工具（Cursor、Claude Code、各类 Coding Agent）：

{
  "apiKey": "sk-你的令牌",
  "baseURL": "http://localhost/v1"
}

③ API 直调curl / 代码

curl http://localhost/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini",
       "messages":[{"role":"user","content":"hi"}]}'

局域网访问：将 localhost 替换为网关主机的内网 IP（Windows 主机用 ipconfig 查询）。

获取令牌

注册账号后即可自助创建令牌；额度与可用模型由管理员配置。

用户

  1. 注册 / 登录控制台 http://localhost:3000
  2. 令牌 → 添加（可设额度 / 有效期 / 模型范围）
  3. 复制 sk-xxx，按上述任一方式接入

管理员

  1. 控制台管理用户与分组（对应分组倍率折扣）
  2. 渠道页维护上游与模型上架
  3. 日志页处理用量与扣费查询

常见问题

报 401 Invalid token？

令牌无效：确认复制完整（无空格 / 截断）、令牌状态正常、额度未用尽。报错中的 request id 可用于精确定位该次调用。

报 503 No available channel？

该模型未上架或对应渠道全部不可用。更换模型，或联系管理员处理渠道。

报 429？

触发限流：可能是每分钟请求数 / token 数超出限额，也可能是上游渠道繁忙。稍后重试；持续出现请提供 request id 反馈。

流式输出卡住 / 断流？

先更换网络或浏览器验证；长回答被截断通常与超时设置相关；仍有问题请携带报错截图与 request id 反馈。

扣费如何计算？

每次调用的 usage（输入 + 输出 token 数）× 模型倍率 × 分组倍率。注意：多轮对话中历史消息每轮都会重新计费，长对话费用递增属正常现象。

数据安全吗？

所有请求经网关服务器转发，客户端与上游凭证相互隔离。请勿在对话中提交密码、密钥等敏感信息。
